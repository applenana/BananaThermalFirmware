## 打印与装订

1. 使用 A4、对应版本表格中的方向、实际大小 100%，普通每张一页输出。拼版已经完成，Word 与打印机驱动保持普通页面模式。
2. 以上表双面翻转方式为起点，先印封面纸的两个文件页，实物确认正反方向和套准，再印整本。不同驱动的方向联动可能有差异。
3. 完整保留所选版本的全部文件页及封二留白：当前 36 面版为 18 个文件页，32 面版为 16 个，28 面初版为 14 个。相邻两文件页为同一张纸的正反面，由外到内按文件顺序套帖。
4. A5 直接对折；A6 在 A4 高度 148.5 mm 处横裁，分成上下两套；A7 在横向 A4 的 x=148.5 mm、y=105 mm 处分切，得到四套。
5. 各套沿小张竖向中线对折：A5 为 x=148.5 mm，A6 为 x=105 mm，A7 为 x=74.25 mm。对齐封面装订虚线，套帖后骑马订。
6. 用最终纸张先做一份校样，检查页码、字号、QR 扫码与正反偏移。软件坐标准确与实体打印机套准是两个环节，设备偏移应通过校准解决。

文案基线为统一固件 v1.8.0 及兼容版本，设备功能以实物配置和安装版本为准。配图从原双光资料线稿裁切，保留按键、接口、传感器引线；示例探头参数表已从印刷配图中排除。新版本独立存放，既有电子手册和全部单光说明书保持原样。

构建脚本为 `scripts/build_dual_print_booklets.py`，内容源为 `scripts/dual_booklet_content.py`。全部页面自动核对文字、安全区、资料页和页序，视觉阶段按本次要求抽样检查。
