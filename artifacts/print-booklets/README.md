## 成册规格与留白

- 每册使用 8 张 A4 纸、双面共 16 个印刷面，中心折叠后为 32 面小册；折后未裁切尺寸约 148.5 × 210 mm。
- 32 面包含封面、封二留白、正文 1–28 页、封三留白、封底。封二和封三整面留白，正文从下一张纸开始。
- DOCX 第 1 页为“封底｜封面”，第 2 页整面空白，这是同一张封面纸的反面，必须保留。
- 正文页码按折后阅读顺序编排，与 Word 的 1–16 个纸面区分。纸面中线用于折叠。
- 白边设计，无满版出血、无裁切标记。正文版心宽 119.5 mm，距折线至少 15 mm，距外侧至少 14 mm。若印厂需要出血、大版或裁切，应由印前人员另行处理，不可直接放大覆盖白边。

## 请印刷公司按此设置

1. 使用 A4 横向、实际大小 100%，每个文件页对应一个纸面。关闭“适应纸张”、小册子、每张多页、二合一及再次拼版。
2. 双面输出，通常使用短边翻转；先制作折叠样本确认机器的实际翻转方向，确保所有页头同向。
3. 完整保留 16 个文件页及其中的空白页。按相邻两页作为同一张纸的正反面。
4. 按文件顺序由外向内套帖，中心折叠并骑马订。不要把小册页面单独裁开再排列。
5. 开始批量印刷前，用最终纸张做一册折叠打样，检查封面方向、页码 1–28 连续、订口留白、细线与小字清晰。纸张厚度、爬移补偿、折订和裁切容差由印厂确认。

使用 Microsoft Word 打开，字体为 Microsoft YaHei（微软雅黑）与 Calibri。当前版使用本机 Word 导出校样；不同软件或缺失字体可能造成变化。如印厂接收 PDF，宜在确认字体的 Word 环境中导出并核对仍为 16 个 A4 横向页面，保留空白页，以单文件页对应单纸面输出。DOCX 中正文、标题、步骤和表格均为原生可编辑内容，图片为内嵌资源。

## 内容与插图

内容依次介绍机身、供电、传感器维护、首次操作、按键与菜单、测温条件、显示与滤波、拍照与备份、校准与报警、排障，最后补充 Studio 和固件维护。正文通过纸质页码互相引用，无须点击链接。

按键与接口采用原说明书线稿，在 Word 中裁取完整的带标注立体视图，保留屏幕朝向、接口位置与标线。背面图沿用依据用户建模参考重绘的白底技术示意。绘图来源与提示词记录见[插图来源](../../docs/assets/devices/PRINT_ARTWORK.md)。

修订文案只介绍本机操作，合并测温、拍照、校准和排障中的重复内容，保留明确的数据清除与供电风险。正文 28 页的目录、交叉引用和套帖页序已同步调整。

触屏为选配，默认款不带触屏，购买时可在购物平台选择触屏版本。两种版本均可通过实体按键操作菜单。触屏章节及图例拖动、触摸排障、备份和迁移检查中的触屏操作均注明适用版本；“触屏调整”相关项目需配合触屏硬件使用。
