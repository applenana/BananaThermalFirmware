## 单光设备随附印刷说明书

[当前推荐：单页顺序 Word 原稿与 Word 小册子操作说明](print-booklets/reading-order/README.md)：三款机型均提供 A6 32 面及 A7 28 面原稿。每个文件只有一本，按阅读顺序每页一个成品面，正文、表格可编辑，无手工 A4 拼版和辅助线；由印厂完成最终合版。以下旧 A4 拼版文件保留作为历史版式参考。

[A7 三款独立说明书与印刷交接要求](print-booklets/a7/README.md)：最新预拼版为 28 面“仅封面装订虚线版”，含正文 24 页；A4 横向四套预拼版，7 张双面 A4 可制作四本约 A7 的说明书。装订虚线仅位于封面与封底之间，封三提供 QQ 群和开源项目资料。原双面辅助线版与 60 面版保留为历史文件，按所选版本的说明做双面套准及小字阅读校样。

[新版 A6 三款独立说明书与印刷交接要求](print-booklets/a6/README.md)：2.4、2.8、3.2 寸单光各一份可编辑 DOCX，A4 竖向上下双套预拼版，8 张双面 A4 纸可制作两本约 A6 的说明书。每本 32 面，含正文 28 页、封面、封二留白、封三资料页、封底。正文沿用触屏选配说明版；新版加入镜像对称裁切虚线、外层纸折订虚线、QQ 群与开源项目资料。原 [A5 横向拼版文件](print-booklets/README.md)及旧 A6/A7 均保留，各版分别交接印刷。
