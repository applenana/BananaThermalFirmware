v1.8 是手册适用的统一固件文档基线，不代表固件附件已经发布。手册覆盖新版单光支持、六固件矩阵、迁移行为、报警和分段校准，并以 Studio 0.5.5 源码核对上位机操作。实际可下载版本请查看正式 Releases。

两册各 20 页，按使用任务重新编排，含可点击目录、机型图、编号操作、报警与对齐示意、固件对照和排障速查。Word 正文和表格可编辑，PDF 与 Word 同版导出。在线说明保留更细的菜单与协议入口。
