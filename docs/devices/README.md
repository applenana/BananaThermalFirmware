# 设备分类与功能对照

Banana Thermal Firmware 现在同时服务双光与单光设备。“普通热成像”“单光热成像”在本仓库均指 `standard` 板型；“双光热成像”指 `dual` 板型。两套板型共享源码和发布版本，但引脚与硬件能力不同，UF2 不可交叉刷写。

## 先认设备 再选固件

| 设备 | 板型 | 主要输入 | 可见光与融合 | 测距与视差 | 使用说明 |
| --- | --- | --- | --- | --- | --- |
| 2.4 寸单光 | `standard` | A/B；新版 A+B 确认 | 无 | 无 | [单光手册](../user-guide/single-light.md#2-三种机型的外观与差异) |
| 2.8 寸单光 | `standard` | A/B；新版 A+B 确认 | 无 | 无 | [单光手册](../user-guide/single-light.md#2-三种机型的外观与差异) |
| 3.2 寸单光 | `standard` | A/B、左右确认拨片 | 无 | 无 | [单光手册](../user-guide/single-light.md#2-三种机型的外观与差异) |
| 3.2 寸双光 | `dual` | A/B、拨片、独立快捷菜单键 | 有，取决于摄像头初始化 | 可选 VL53L0X | [双光手册](../user-guide/dual-light.md) |

三种单光机型在 Flash 容量相同、运行配置相同时使用同一个 `standard` UF2。屏幕尺寸、传感器型号和 Flash 容量是不同维度，不能互相推断。3.2 寸设备既可能是单光，也可能是双光。

旧版外壳资料记载：2.4/2.8 寸向右开机、向左关机；3.2 寸单光向左开机、向右关机。方向描述随观察面变化，实际操作以外壳 ON/OFF 标记为准。

## 共用能力与硬件条件

| 功能 | standard 单光 | dual 双光 |
| --- | --- | --- |
| 热像、色板、滤波、温度图例、测温光标 | 支持 | 支持 |
| 全屏与方屏、温度报警、温度校准 | 新统一固件支持 | 新统一固件支持 |
| 本机照片与相册、Studio 温度趋势和图库 | 支持 | 支持 |
| 触摸与手势 | 依实物是否安装并成功初始化触摸硬件 | 同左 |
| 摄像头与双光融合 | 不支持；设备菜单可能保留“不可用”提示 | 摄像头初始化成功后可用 |
| 视差与距离菜单 | 不提供 | VL53L0X 初始化成功后显示 |
| 实体快捷菜单键 KEY2 | 不提供 | 提供 |
| Studio 可见光控件 | 识别 standard 后隐藏 | 按设备能力显示 |

新版菜单为基础 15 个栏目，其中摄像头和融合在单光上为不可用占位；双光检测到距离传感器后再增加 2 个栏目，共最多 17 个。不要把菜单数量或某个占位文字作为硬件识别依据。
