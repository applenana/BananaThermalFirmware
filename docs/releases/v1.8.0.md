# Banana Thermal Firmware v1.8.0

本版本首次提供 dual 双光热成像与 standard 普通热成像统一源码的六固件发布，并启用 manifest schema v2。请先安装支持 schema v2 的新版 NextBananaThermalStudio，再进行固件迁移或升级。

- dual 与 standard 不得交叉刷写；Studio 会按设备身份锁定板型。
- 每个板型均提供 8 MB 性能版、8 MB 稳定版和 2 MB 版。
- 旧普通热成像首次迁移会格式化 LittleFS，清除照片、配置和校准；有效激活信息仅在旧分区可挂载时尝试恢复。
- 主动切换 2 MB / 8 MB 分区前必须备份，且可能需要重新激活。
- 屏幕尺寸不再决定构建环境；Heimann、MLX90640 与 MLX90641 继续由运行时自动识别。

## 使用文档更新

- 新增覆盖 2.4 / 2.8 / 3.2 寸的[单光手册](https://github.com/applenana/BananaThermalFirmware/blob/main/docs/user-guide/single-light.md)，包含三种外壳、两键组合菜单和拨片差异。
- 更新[双光手册](https://github.com/applenana/BananaThermalFirmware/blob/main/docs/user-guide/dual-light.md)，两套手册均提供[DOCX 与 PDF](https://github.com/applenana/BananaThermalFirmware/blob/main/artifacts/README.md)。
- standard 禁用摄像头、距离模块和独立快捷键；Studio 按身份隐藏双光控件，本机相机与融合栏目可能保留不可用提示。
- 单光默认按传感器类别应用：MLX 旋转 180°、32 Hz；Heimann 不旋转、Q=0.5、R=1.75；两类每帧卡尔曼次数为 8。
- 手册同步现有温度报警与分段校准实现，菜单基础 15 项，测距成功后最多 17 项。
- 修正 MLX90641 原生 16×12、固件上采样到 32×24 的说明。

本文描述 v1.8.0 对应源码及发布约定，不代表附件已经发布；实际下载以正式 Releases 为准。

附件选择与校验方法见[固件变体说明](https://github.com/applenana/BananaThermalFirmware/blob/main/docs/FIRMWARE_VARIANTS.md)和[发布完整性与签名](https://github.com/applenana/BananaThermalFirmware/blob/main/docs/RELEASE_INTEGRITY.md)。
