# 香蕉热成像固件 v1.7.0

这是公开固件分发通道的首个正式版本。请根据设备 Flash 容量选择正确的 UF2，并在刷写前校验随 Release 提供的 SHA-256 与 Ed25519 签名。

## 主要更新

- 新增浮动温度图例：支持六个预设位置、触摸拖动和重启后恢复；
- 图例透明度支持 `0% / 25% / 50% / 75% / 100%`，透明度与数字、单位、刻度显示开关彼此独立；
- 反色设置增加 LCD 的 RGB / BGR 色序切换，并保存到设备配置；
- 新增热点追踪及其持久化设置；
- 新增线性温度校准查询、设置和恢复接口，并提高校准参数保存精度；
- 新增 `thermal view` 查询，用于上位机复原传感器、屏幕模式、热流尺寸、缩放、偏移和旋转；
- 照片格式升级并补充热像视图参数，改善照片预览中的方屏、极值和测温一致性；
- 改善 MLX 与 Heimann 在全屏、方屏、缩放和偏移情况下的坐标映射。

## 构建与兼容性

- 固件内部版本与 Release Tag 绑定，可通过系统信息中的 `firmwareVersion` 核对；
- 8MB 正常版：3MB 程序区 + 5MB LittleFS，300MHz；
- 8MB 稳定版：3MB 程序区 + 5MB LittleFS，220MHz；
- 2MB 兼容版：1MB 程序区 + 1MB LittleFS；本版本修正了该变体的实际 Flash 链接范围；
- 建议配合最新版 [NextBananaThermalStudio](https://github.com/applenana/NextBananaThermalStudio/releases) 使用。

## 升级前须知

- 切换 8MB 与 2MB 分区方案前，请先备份照片、校准值和重要设置；
- 不能确认 Flash 容量时，不要依靠 UF2 文件大小猜测；
- 图例 100% 透明只隐藏背景，不会自动隐藏温度数字或刻度；
- 刷写后请检查固件版本、热成像传感器识别、方屏/全屏、可见光和 USB 推流。

完整步骤见[安装与升级指南](../INSTALLATION.md)，固件选择见[固件变体说明](../FIRMWARE_VARIANTS.md)。
