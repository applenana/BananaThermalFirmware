## 设备做什么

单光设备显示热阵列测得的温度分布；双光设备再叠加可见光轮廓，两路不在同一物理位置，近距离可能需要视差补偿。先看[设备分类](../devices/README.md)：2.4 / 2.8 / 3.2 寸单光共用 standard 固件，3.2 寸双光使用 dual。

三款单光的外壳图、开关方向、两键操作和复位差异见[单光完整手册](single-light.md)。下图是双光设备，不能据此寻找单光上的快捷键、摄像头或测距模块。

![设备结构示意](../assets/user-guide/device-controls.png)

图中是特定双光配置，不能作为所有设备的型号、量程或精度保证。实际传感器与有效测量范围以设备和对应探头资料为准。

## 主要部件

| 部件 | 作用 | 使用要点 |
| --- | --- | --- |
| 电源开关 | 控制整机电源 | 开机后等待传感器初始化；正在写入、下载或刷机时不要断电 |
| 菜单拨片 / 左右确认键 | 进入菜单、选择、编辑 | 按下表示进入/确认，左右拨动表示选择或增减 |
| 按钮 A | 清理测温标记、切换伪彩、相册删除 | 长按约 1 秒循环 7 套伪彩 |
| 按钮 B | 拍照、退出冻结、进入相册 | 短按拍照，长按约 1 秒进入设备相册 |
| 快捷菜单键 | 双光专用，打开悬浮快捷菜单 | 单光无此键，改用详细菜单 |
| 复位键 | 立即重启 | 刷机时与按钮 A 配合进入 UF2 Bootloader |
| Type-C | 供电、充电、USB 串口 | 仅充电线不能连接 Studio |
| 充电灯 | 指示充电状态 | 常见为充电亮、充满灭；不同批次可能略有差异 |

## 主画面状态栏

| 字段 | 含义 | 注意 |
| --- | --- | --- |
| 最高温 / 最低温 | 当前可见热像区域的极值 | 缩放、平移、方屏裁剪和旋转都会改变统计区域 |
| 融合 | 当前双光模式 | 无摄像头时相关状态不可用 |
| 电量 | 估算电池百分比 | 异常跳变先查供电和电池连接 |
| 耗时 | 单帧处理/渲染毫秒数 | 长期偏高可能是滤波、融合或推流负载过重 |
| 距离 | VL53L0X 距离或范围状态 | `N/A` 为模块不可用；`>2m` / `>3m` 为超范围，不是精确值 |

## 热像分辨率不要和屏幕混淆

| 模式 | 真实温度阵列 | 屏幕 / Studio 行为 |
| --- | --- | --- |
| 全屏，任意传感器 | 32×24 | LCD 320×240；Studio 接收 768 个 float32 |
| 方屏，MLX | 32×24 | LCD 240×240；按方屏视图参数裁剪/缩放，不补造温度行 |
| 方屏，Heimann | 32×32 | LCD 240×240；Studio 接收 1024 个 float32 |

屏幕放大只改变观看方式，不增加真实测温点。小目标应尽量覆盖多个热像素。

## 5 分钟快速上手

1. 用可靠的 Type-C 数据线连接电源或电脑，打开设备。
2. 等待启动和传感器初始化完成；报错时先重启并检查供电。
3. 对准温差明显、表面哑光且能覆盖多个热像素的目标。
4. 长按 A 选择易辨认的伪彩；画面抖动时从轻度二次滤波开始。
5. 短按 B 拍照并冻结，再按 B 返回；长按 B 进入相册。
6. 需要电脑或 Android 投屏时，保持 USB 连接并在 Studio 中执行“自动连接”。

## 功能为什么可能少一项

- 热阵列可能为 MLX90640（原生 32×24）、MLX90641（原生 16×12，固件上采样至 32×24）或 Heimann HTPA32x32（原生 32×32）。
- 摄像头可能为 OV2640 / OV3660；缺少或初始化失败时，相机与融合选项不可用。
- VL53L0X 是可选件；只有初始化成功时才显示测距、自动视差与相关锚点功能。
- 旧款机型可能没有独立拨片确认：A/B 充当左右，A+B 充当确认。

- standard 单光不提供摄像头、融合、距离和独立快捷菜单键；本机可能保留不可用栏目，Studio 会按身份隐藏双光操作。
- 触摸和手势取决于实物硬件及初始化，不能仅按屏幕尺寸推断。
