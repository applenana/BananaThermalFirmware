## 双光对齐的正确顺序

本节仅适用于 dual。standard 单光不含摄像头和距离模块，直接阅读后面的测温与校准部分；三款机型的实体操作见[单光手册](single-light.md)。

双光重影首先是几何问题。透明度、边缘阈值和 Gamma 只能改变观感，不能修复错位。

1. 关闭自动视差，选择要校准的全屏或方屏模式。
2. 找一个中等距离、边缘清楚且温差明显的目标。
3. 调可见光缩放，使两路目标大小接近。
4. 调可见光 X/Y 完成粗对齐，再用热像 X/Y 小幅精调。
5. 检查旋转、水平/垂直镜像和红蓝色序。
6. 有 VL53L0X 时校准测距偏移，再设置视差锚点。
7. 在近、中、远三个距离检查；切换另一屏幕模式后单独重做。

### 视差与测距

- 自动视差只在 VL53L0X 初始化成功时可用。
- 自动基准用于建立当前基础位置；锚点描述不同距离下的补偿。
- `N/A` 表示测距不可用；`>2m` / `>3m` 是超范围状态，不应作为精确标定数据。
- 锚点应覆盖设备实际使用距离并保持单调合理，避免极近距离的抖动读数。

菜单参数详见[摄像头](../menu/10-camera.md)、[融合](../menu/11-fusion.md)、[视差调整](../menu/15-parallax.md)和[距离传感器](../menu/16-distance-sensor.md)。

## 测温准确性的四个层级

1. **目标覆盖**：目标尽量覆盖多个热像素，避开画面边缘和强烈背景温差。
2. **表面发射率**：皮肤、哑光涂层常从 0.95–0.98 起试；亮面金属容易测到环境反射。
3. **环境与距离**：避免气流、玻璃隔挡、镜面反射和过远小目标。
4. **线性校准**：只有前面条件稳定后，才用 `T校准 = T原始 × gain + offset` 修正系统误差。

低发射率表面可在允许时贴已知高发射率胶带，等待热平衡后测胶带。滤波不能修复发射率错误。

## Studio 温度校准

新版支持兼容单直线和最多 128 段的连续分段曲线。先读取设备能力与原曲线，再按向导采样、检查误差并写入。菜单可显示段数、温区、整体权重和偏置；详见[温度校准](../menu/04-temperature-calibration.md)。下面两点拟合仅适用于单直线，不会代替分段曲线的校验。

1. 连接设备并开启热像流，在设置页打开校准向导。
2. 读取当前 gain、offset 和存储状态。
3. 用均匀恒温目标覆盖中央采样框，稳定后输入参考温度并采集。
4. 至少采集两个不同温点，推荐跨度不小于 10℃；单点标准差尽量不超过约 0.2℃。
5. 检查拟合公式、RMSE 和每个点的残差。跨度太小或残差过大时刷新并重新采集。
6. 确认 gain 在 0.5–1.5、offset 在 -100–100℃，再写入并保存。
7. 用第三个未参与拟合的温点复核；需要完全恢复时使用明确的“恢复默认”流程。仅把整体权重改为 1.00、偏置改为 0.00 不会删除已有分段曲线。

校准会影响之后的本机、照片和 Studio 温度，但不会改写旧照片里已经保存的历史温度。

## UF2 升级

| 文件后缀 | 硬件 | 选择原则 |
| --- | --- | --- |
| `<profile>_sketch3m_fs5m.uf2` | 8 MB，300 MHz | 默认性能版 |
| `<profile>_sketch3m_fs5m_stable.uf2` | 8 MB，220 MHz | 稳定版 |
| `<profile>_sketch1m_fs1m.uf2` | 2 MB | 小容量设备 |

`<profile>` 必须为实物对应的 dual 或 standard，不能交叉选择。完整六项见[固件变体](../FIRMWARE_VARIANTS.md)。旧单光首次迁移会重建存储，不能套用“普通升级后旧照片仍在”的预期。

升级前下载照片并记录发射率、温度/触摸校准、双光对齐和视差锚点。完整的校验、Bootloader 和刷写步骤见[安装与升级指南](../INSTALLATION.md)。

## 串口控制台与命令分级

先用只读命令收集状态，再执行单一写入并立即回读。激活算法、私钥和寄存器级危险写入不属于公开手册。

| 级别 | 命令 / 命令族 | 用途 |
| --- | --- | --- |
| 只读 | `help`、`GetSysInfo`、`ucode`、`thermal view` | 帮助、系统/识别信息、当前 Thermal View JSON |
| 只读 | `calibration get`、`filter show`、`badpix list` | 读取校准、滤波与坏点表 |
| 状态 | `fusion`、`cam` | 不带写入参数时查看图像状态；回显随版本变化 |
| 校准写入 | `calibration set <gain> <offset>`、`calibration reset` | 写入或恢复线性校准；写后回读 |
| 分段校准 | `calibration2 get/begin/chunk/commit/abort/reset` | 由新版 Studio 管理传输和校验，避免手工发送不完整曲线 |
| 温度报警 | `alarm get/set/ack/defaults` | 查询、配置、确认和恢复默认，详见[报警说明](../menu/17-temperature-alarm.md) |
| 旧版兼容 | `cali -w0` / `-b0` / `-show`、`save` | 旧固件分项校准与保存；新版本优先用 Studio 向导 |
| 滤波写入 | `filter set …`、`kalman set_* …` | 改滤波参数；先记录旧值，一次只改一项 |
| 坏点维护 | `badpix add/del/clear/on/off/test` | 管理坏像素表、启停补偿与测试 |
| Studio 托管 | `check`、`download <filename>`、`stream`、`vstream`、停止命令 | 照片列表/下载、热像/可见光流；不要与 Studio 并发手发 |
| 破坏性 | `clean` | 清理数据/配置，不可恢复；必须先完整备份 |
| 受控流程 | `activate <code>` | 只使用售后提供的码；不得公开序列号或激活码 |

### 坏点修正

1. 用 `badpix list` 记录当前表。
2. 在均匀场景确认某像素持续异常，而不是瞬时噪声或真实小热点。
3. 用 `badpix test` 和开/关补偿对比。
4. 只有确认坐标后才 `add`；`del` / `clear` 前保留原列表。
5. 重启后再次检查持久化与邻域插值结果。

## 安全排障顺序

1. 停止录像、设备图库下载和升级。
2. 保存 `GetSysInfo`、`thermal view`、`calibration get`、`filter show`、`badpix list` 的脱敏回显。
3. 一次只改一个参数；不要粘贴来源不明的命令串。
4. 回读、重启、复测；变差时恢复先前记录值。
5. 涉及 `clean`、激活或未知写入时停止并联系维护人员。

常见异常见[故障排查](../TROUBLESHOOTING.md)，公开数据格式见[下一章](06-data-formats.md)。
