## 按键在不同界面中的行为

| 输入 | 主画面 | 菜单 / 快捷菜单 | 设备相册 |
| --- | --- | --- | --- |
| 左拨 / 左键 | 快捷菜单关闭时降低二次滤波；开启时上一项/减值 | 上一项；编辑时减值，长按加速 | 上一张 |
| 按下拨片 / 确认 | 打开详细菜单；快捷菜单中进入/退出编辑 | 进入、确认、切换编辑；在“返回”处保存 | 取消删除提示或执行当前确认 |
| 右拨 / 右键 | 快捷菜单关闭时提高二次滤波；开启时下一项/增值 | 下一项；编辑时增值，长按加速 | 下一张 |
| A 短按 | 清多点 → 隐藏主光标 → 隐藏冷热追踪 → 恢复 | 旧款机型充当左键 | 第一次提示删除，第二次确认删除 |
| A 长按 | 循环 7 套伪彩 | 连续左移 | 保持相册行为 |
| B 短按 | 拍照并冻结；再按退出 | 旧款机型充当右键 | 退出相册 |
| B 长按 | 进入设备相册 | 连续右移 | 保持照片预览 |
| A+B | 旧款机型等同确认 | 进入/确认/切换编辑 | 取消删除流程 |
| 快捷菜单键 | 开启/关闭快捷菜单 | 关闭时保存，修改约 3 秒后自动保存 | 无主要操作 |

> 相册删除不可恢复：按钮 A 需要连续确认两次；重要照片先通过 Studio 下载。

## 快捷菜单

1. 按快捷菜单键进入浏览状态。
2. 左右选择条目；按下拨片进入编辑。
3. 左右调值；再次按下退出编辑；停止操作约 3 秒后保存。

| 组别 | 条目 |
| --- | --- |
| 高频显示 | 全屏、亮度、色板、可见光缩放 |
| 距离对齐 | 视差模式、自动基准、可见光 X、可见光 Y |
| 像素对齐 | 热像缩放、热像 X、热像 Y |
| 融合效果 | 融合模式、混合比例、Gamma、边缘颜色 |

没有摄像头时对应值显示 `N/A`；没有 VL53L0X 时视差模式和自动基准会隐藏。详细菜单亮度为 0–256；快捷菜单为避免误触近似黑屏，只允许 5–256。

## 触摸与手势

- 触屏检测开启时，可点击画面放置手动点温、多点标记或拖动自定义图例。
- 手势检测开启后：下滑进入菜单、上滑退出、左右滑等同左右键、点击等同确认。
- 图例拖动优先于滑动手势，不会同时翻页。
- 校准时依次点击左上和右下目标点，再检查四角与中心；偏差明显时用实体键重新进入校准。
- 关闭触摸后实体按键仍可完整操作设备。

## 全屏、方屏与独立配置

全屏为 320×240，方屏为 240×240。切换模式时，固件会保存旧模式的热像/可见光缩放和偏移，再加载新模式配置。调好全屏不会自动调好方屏；两种模式应分别对齐。

### 常见参数关系

- 卡尔曼是跨帧时间滤波；二次滤波是同帧空间平滑。两端都过强会拖尾并抹掉小热点。
- 发射率和线性校准会改变温度；伪彩、Gamma、图例、反色、缩放只改变显示。
- 融合重影先处理几何对齐，不能靠透明度或边缘阈值掩盖。
- “格式化硬盘”操作的是 LittleFS，会清照片和大部分配置；执行前必须下载备份。

需要完成双光对齐或校准时，阅读[高级设置与维护](05-advanced-and-service.md)。
