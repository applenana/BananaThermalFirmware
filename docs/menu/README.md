# 设备菜单完整指南

本指南依据香蕉热成像设备当前固件的实际菜单、默认值和处理链路编写。每个一级栏目都有独立页面，既说明“怎么调”，也解释“为什么要调”和它会影响哪一段图像或测温链路。

> 不同硬件批次可能没有摄像头、VL53L0X 距离传感器，或使用不同的热成像传感器。固件会按实际检测结果隐藏不适用的选项。

## 操作方法

- 中键：进入菜单、进入栏目、确认当前参数进入编辑状态。
- 左键 / 右键：移动选项；编辑状态下减小 / 增大或切换参数。
- 返回菜单：保存本次设置并返回上一级。
- 启用触摸手势后：下滑进入菜单，上滑退出菜单，左右滑等同左右键，点击等同中键。

设备通常会在离开栏目时保存设置。格式化存储属于破坏性操作，不遵循普通参数的保存语义。

## 理解处理链路

这些设置并非都作用在同一个位置。简化后的处理顺序如下：

```text
传感器原始温度
  → 发射率补偿
  → 温度校准（增益 × 温度 + 偏移）
  → 卡尔曼时间滤波
  → 旋转 / 方屏链路复原 / 热像缩放与偏移
  → 空间滤波与插值
  → 自动温度范围、伪彩映射
  → 可见光融合、测温光标、图例与屏幕输出
```

上位机接收的是温度数组和独立的视图描述，不应把屏幕上已经放大、着色的画面误当作原始热流。详见[传感器与显示模式](../SENSORS_AND_DISPLAY.md)和[双光串口推流协议](../STREAMING_PROTOCOL.md)。

## 与上位机的关系

[NextBananaThermalStudio](https://github.com/applenana/NextBananaThermalStudio)会在电脑或 Android 设备上重新完成热像链路复原、色板映射、图例和分析。两边名称相似的滤波或图例设置并不代表共享同一状态：

- 设备菜单设置主要影响设备本机 LCD；
- 发射率和设备温度校准会改变设备输出温度，因而也影响上位机；
- 上位机自己的卡尔曼、色板、图例和画面布局只影响上位机显示；
- `thermal view` 返回屏幕模式、传感器、热流尺寸、缩放、偏移和旋转，供上位机复原设备视图。
