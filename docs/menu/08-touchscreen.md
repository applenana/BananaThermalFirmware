# 触屏调整

上一篇：[伪彩调整](07-colormap-and-legend.md) · [返回菜单总览](README.md) · 下一篇：[全屏调整](09-display-mode.md)

本栏目控制触摸输入、滑动手势以及触摸坐标校准。关闭触摸后，实体按键仍可操作设备。

## 参数与操作

| 项目 | 选项 / 行为 | 当前默认值 |
| --- | --- | --- |
| 手势检测 | 开 / 关 | 关 |
| 触屏检测 | 开 / 关 | 开 |
| 触屏校准 | 依次触摸左上角和右下角参考点 | 使用固件预设原始边界 |

当前预设原始触摸范围约为：

```text
X: 200–3850
Y: 400–3920
```

每块触摸面板和装配方向可能不同，预设值只是默认起点。

## 手势含义

启用手势后：

- 下滑：进入菜单；
- 上滑：退出菜单并回到画面；
- 左滑：等同左键；
- 右滑：等同右键；
- 点击：菜单打开时等同中键确认。

固件主要按起点与终点的位移识别手势，不是连续多指手势系统。短距离抖动、斜向拖动或图例拖动可能不会被识别为上述动作。

## 触屏校准

校准会记录两个角点对应的原始坐标，用于把触摸控制器读数映射到屏幕坐标。

1. 清洁屏幕并保持设备稳定；
2. 用细而不尖锐的触控工具准确点按第一个角点；
3. 再准确点按对角角点；
4. 完成后测试屏幕四角和中心；
5. 若偏差反而更大，使用实体按键重新进入本栏目再次校准。

## 与其他功能的关系

- [测温光标](06-measurement-cursor.md)的手动点和多点测温依赖准确的触摸坐标。
- [伪彩图例](07-colormap-and-legend.md)选择“自定义”后可触摸拖动；图例正在拖动时不会同时触发滑动手势。
- 关闭“触屏检测”会停用触摸测温和拖动，但不会停用实体按键或 USB 推流。

## 排查

| 现象 | 检查 |
| --- | --- |
| 点击位置整体偏移 | 重新校准两个角点 |
| 左右或上下完全相反 | 检查硬件批次、屏幕方向和固件变体 |
| 滑动总被当作点击 | 增大滑动距离并减少斜向移动 |
| 无法用触摸恢复 | 使用实体按键进入菜单 |
