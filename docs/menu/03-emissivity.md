# 发射率

上一篇：[卡尔曼滤波](02-kalman-filter.md) · [返回菜单总览](README.md) · 下一篇：[温度校准](04-temperature-calibration.md)

发射率描述物体表面把热辐射发射出来的能力，通常记为 `ε`，理想黑体为 `1.00`。红外传感器看到的是辐射，不是直接接触到的温度；材料表面、光泽、氧化层和观察环境都会影响换算结果。

菜单用百分比显示：

```text
菜单 95% = 计算时 ε 0.95
```

## 参数

| 参数 | 范围 | 当前默认值 | 说明 |
| --- | --- | --- | --- |
| 发射率 | `0–100%`，步长 `1%` | `100%` | 用于传感器温度计算或传感器驱动补偿 |

## 常见起点

以下仅适合作为起始参考，精确测量应依据材料资料和标定条件：

| 表面 | 可尝试的起始值 |
| --- | --- |
| 人体皮肤、哑光涂层、胶带 | 约 `95–98%` |
| 木材、纸张、塑料、墙面 | 通常为较高发射率，但会随材料而变 |
| 氧化金属 | 通常高于同材质抛光表面 |
| 光亮或抛光金属 | 往往较低，且强烈反射周围热源，直接测量容易失真 |

对低发射率物体，更可靠的办法通常是在允许的情况下贴一小块已知高发射率胶带，等待它与物体达到相同温度后测量胶带。

## 传感器差异

- MLX90640 / MLX90641：固件在每帧温度计算时把菜单值转换为 `0.00–1.00` 使用。
- Heimann HTPA32x32：通过传感器驱动设置发射率，并持久化到对应配置。

两种传感器的实现路径不同，但目标都是修正辐射温度。不要把发射率与[伪彩图例透明度](07-colormap-and-legend.md)混淆：前者会改变温度结果，后者只改变界面背景。

## 注意事项

- 菜单当前允许设置到 `0%`，但零发射率不适合作为正常测温参数，部分计算还可能变得无意义。实际使用不要设为 `0%`。
- 发射率设错会造成系统性温差，后续卡尔曼滤波无法修正这种偏差。
- 镜面反射会把操作者、灯具、天空或其他热源的红外辐射反射进传感器；仅修改发射率不一定能解决。
- 追求可追溯精度时，应在明确的距离、环境温度和参考黑体条件下做[温度校准](04-temperature-calibration.md)。

## 与上位机的关系

发射率在设备端参与温度生成，因此上位机收到的浮点温度已经受它影响。上位机不应在不知道设备处理状态时重复进行同一种发射率补偿。
