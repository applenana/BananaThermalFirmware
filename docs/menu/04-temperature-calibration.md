# 温度校准

上一篇：[发射率](03-emissivity.md) · [返回菜单总览](README.md) · 下一篇：[硬盘管理](05-storage.md)

单光与双光共用温度校准。新版支持单直线及最多 128 段的连续分段曲线；旧 `calibration` 接口继续兼容，新版 Studio 另协商 `calibration2` 能力。下面的公式只描述单直线校准：

```text
校准后温度 = 原温度 × 权重 + 偏移
```

它适合修正整体比例误差和固定偏差，不负责修复单个坏点、反射干扰或错误发射率。

## 参数

新版菜单有 5 个子项：曲线段数、温区、整体权重、整体偏置、恢复默认。分段曲线不能仅用一组 gain/offset 描述；下表参数用于单直线与整体微调。把整体权重改回 1、偏置改回 0 不会删除已有曲线，需要完全恢复时使用明确的“恢复默认”操作。

| 菜单参数 | 数学含义 | 当前默认值 | 菜单步长 |
| --- | --- | --- | --- |
| 权重 | 增益 `gain` | `1.00` | `0.01` |
| 偏移 | 偏置 `offset`，单位 °C | `0.00` | `0.01` |

示例：权重 `1.02`、偏移 `-0.50` 时，设备读到 `30.00°C` 会输出 `30.10°C`。

## 推荐校准方法

要同时求权重和偏移，至少需要两个分布足够开的可靠参考温度点。若传感器在两个参考点的读数为 `M1`、`M2`，参考真值为 `T1`、`T2`：

```text
权重 = (T2 - T1) / (M2 - M1)
偏移 = T1 - 权重 × M1
```

校准前应：

1. 先设置正确的[发射率](03-emissivity.md)；
2. 让设备和参考目标达到稳定状态；
3. 固定距离、角度和环境，保证目标充分填充测量区域；
4. 在每个参考点采集一段时间的平均值，而不是只读一帧；
5. 校准后用第三个温度点验证，而不是只验证参与计算的两个点。

## 设备菜单与上位机向导

菜单适合查看和小幅手工微调。[NextBananaThermalStudio](https://github.com/applenana/NextBananaThermalStudio)的新版向导负责读取设备能力和完整曲线、采样、拟合、检查残差与写入。先备份原参数，再按向导选择单直线或分段校准；写入后回读并用未参与拟合的温点验证。

对应串口入口见[温度校准协议](../STREAMING_PROTOCOL.md#温度校准协议)。兼容单直线接口对写入范围有保护：

- 权重：`0.5–1.5`
- 偏移：`-100–100°C`

复杂曲线请由 Studio 管理 `calibration2 get/begin/chunk/commit/abort/reset` 的事务、分块、CRC 和超时，不建议手工发送不完整数据。首次旧单光迁移会清空校准，详见[安装与升级](../INSTALLATION.md)。

## 处理顺序

发射率补偿完成后，固件先应用本项线性校准，再进入卡尔曼和显示处理。因此：

- 卡尔曼只能平滑校准后的温度，不能替代标定；
- 上位机收到的是已经线性校准的温度，不应无条件重复应用同一参数；
- 单直线默认权重为 `1.00`、偏移为 `0.00`；已有分段曲线时须使用恢复默认流程才能清除曲线。
