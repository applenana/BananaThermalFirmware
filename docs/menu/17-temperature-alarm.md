# 温度报警

上一篇：[传感器设置](14-sensor.md) · [菜单总览](README.md) · 下一篇：[视差调整](15-parallax.md)

本栏目适用于新版单光和双光。过热根据设备当前有效热像视区最高温判断，过冷根据最低温判断，不以中心点温度为判据。报警依据已经应用当前校准的温度。

## 参数与默认值

| 参数 | 默认 | 范围或行为 |
| --- | --- | --- |
| 总开关 | 关闭 | 开启后仍需启用高温或低温通道 |
| 高温通道与阈值 | 关闭，60 °C | -39 至 300 °C |
| 低温通道与阈值 | 关闭，0 °C | -40 至 299 °C，必须低于高温阈值 |
| 高温与低温迟滞 | 各 2 °C | 0.1 至 20 °C |
| 触发延时 | 500 ms | 0 至 10000 ms |
| 解除延时 | 1000 ms | 0 至 10000 ms |
| 锁存 | 关闭 | 开启后温度恢复也需确认解除 |
| 重复上报 | 1000 ms | 0 表示关闭；否则 250 至 60000 ms |
| 解除当前报警 | 操作项 | 确认 H/L 活动通道，需等待回到恢复区后重新布防 |

阈值允许设置的范围不是传感器的准确测量范围。实际量程、精度和校准条件取决于探头。

## 设置步骤

1. 进入“温度报警”，设置阈值与迟滞，启用需要的通道和总开关。
2. 在“返回”处确认保存，重新进入或用 `alarm get` 回读。
3. 用可控温源让温度跨过阈值，等待触发延时，观察本机与 Studio 状态。
4. 让温度回到迟滞恢复区，验证解除延时；开启锁存时执行确认解除。
5. 重启复核设置。需要外部声光报警时单独配置支持协议的控制器。

例如高温阈值 60 °C、迟滞 2 °C：最高温持续达到 60 °C 并满足延时才触发；下降到 58 °C 或以下并满足解除延时才自动解除。锁存开启时仍需用户确认。

确认解除后，即使温度仍越界，通道也保持已确认状态；至少回到一次恢复区后才重新布防。断连或无效温度不代表恢复正常；数据无效时不会触发新报警，也不会自动解除已有报警。

## 串口与外部报警器

事件为固定 ASCII 行，例如 `!A,1,H,1,+0850` 加 LF，表示高温通道活动、当前温度 85.0 °C。H/L 为独立通道，状态 1 为活动、0 为解除或确认。事件可以与热帧、可见光帧及照片下载记录共存，但不会插入已开始的二进制帧载荷内部。

配置命令为 `alarm get`、`alarm set`、`alarm ack`、`alarm defaults`。写入后应检查响应中的 `persisted`，为 false 时不能报告已保存。需要精确参数顺序和测试向量时，使用 [Studio 仓库完整报警协议](https://github.com/applenana/NextBananaThermalStudio/blob/main/docs/protocol_temperature_alarm.md)。

固件报警不代表设备内置蜂鸣器。Studio 可把事件转发到第二个串口连接的用户报警模块；接入时分别测试两个通道、确认、重新布防与断连行为。
