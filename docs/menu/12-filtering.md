# 滤波设置

上一篇：[融合](11-fusion.md) · [返回菜单总览](README.md) · 下一篇：[反色设置](13-color-inversion.md)

本栏目主要控制一帧内部的空间平滑和显示温区，不是[卡尔曼时间滤波](02-kalman-filter.md)。

## 参数

| 参数 | 选项 / 范围 | 当前默认值 | 作用 |
| --- | --- | --- | --- |
| 快速插值 | 开 / 关 | 关 | 开启时跳过二次空间滤波，直接做双线性插值 |
| 二次滤波 | 关闭 / 轻度 / 中度 / 强度 | 轻度 | 按邻近热像素平滑当前帧 |
| 最小显示温差 | `0.1–20.0°C`，步长 `0.1°C` | `2.0°C` | 限制自动伪彩范围的最小跨度 |

## 快速插值

开启后，设备省去邻域空间滤波，直接把低分辨率热像双线性放大：

- 优点：计算量更低，边缘响应直接；
- 缺点：坏点、像素噪声和块状感可能更明显；
- 不会关闭卡尔曼，也不会改变热传感器真实刷新率。

## 二次滤波强度

固件使用中心、上下左右和对角像素的加权平均：

| 强度 | 近似权重特点 | 视觉效果 |
| --- | --- | --- |
| 关闭 | 不做邻域平均 | 细节最多，噪声也最明显 |
| 轻度 | 中心权重高，少量十字邻域 | 默认折中 |
| 中度 | 增加十字和对角影响 | 更平滑，细小热点变钝 |
| 强度 | 邻域影响最大 | 最平滑，空间拖影和细节损失最大 |

在主画面且快捷菜单关闭时，左右实体键还会循环切换二次滤波强度。

## 最小显示温差

设备通常按当前画面的最低温和最高温自动铺满色板。当场景接近恒温时，极小噪声也可能被拉伸成剧烈颜色变化。本参数为显示范围设置下限。

例如画面真实最低 `25.0°C`、最高 `25.4°C`：

- 最小显示温差 `0.1°C`：色板可把 `0.4°C` 差异铺得很满，灵敏但容易闪；
- 最小显示温差 `2.0°C`：会把显示范围撑到至少 `2.0°C`，画面更稳定；
- 最小显示温差 `10.0°C`：细微温差可能几乎看不出。

它只影响伪彩映射和图例范围，不应改变点测温原始数值。

## 怎样组合

| 目标 | 建议起点 |
| --- | --- |
| 手持巡检，兼顾响应与稳定 | 卡尔曼默认 + 轻度空间滤波 + `2°C` |
| 寻找微弱温差 | 低空间滤波 + 较小显示温差；同时防止噪声误判 |
| 快速移动目标 | 较弱卡尔曼 + 快速插值或轻度空间滤波 |
| 静态观察且画面闪烁 | 适当增强卡尔曼、空间滤波或最小显示温差 |

设备与[NextBananaThermalStudio](https://github.com/applenana/NextBananaThermalStudio)都可能做显示滤波。两端滤波叠加过强会掩盖小目标并增加观感延迟。
