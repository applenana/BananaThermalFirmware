# 距离传感器

上一篇：[视差调整](15-parallax.md) · [返回菜单总览](README.md)

> 本栏目只在 VL53L0X 初始化成功后显示。

VL53L0X 使用飞行时间原理估算目标距离。设备主要用它为[自动视差](15-parallax.md)提供距离输入，不应把它当作精密测距仪。

## 栏目内容

| 项目 | 范围 / 行为 | 说明 |
| --- | --- | --- |
| 实测距离 | 只读，单位 m | 显示当前有效距离或超量程状态 |
| 调节步长 | 自适应 / `0.001 / 0.01 / 0.1 / 1.0` | 控制手工调整 XTalk 的增减量 |
| 串扰补偿 XTalk | `0–64 MCPS` | 补偿盖板、窗口或内部反射带来的虚假回波 |
| 开始校准 | 采集约 50 个样本 | 自动估算 XTalk |
| 清除校准 | 把 XTalk 设为 `0` | 移除当前串扰补偿 |

自适应步长大致随当前 XTalk 变化：

- 小于 `1 MCPS`：步长 `0.01`；
- `1–10 MCPS`：步长 `0.1`；
- 大于等于 `10 MCPS`：步长 `1`。

## XTalk 是什么

传感器前方的保护窗、外壳、胶水或污渍可能把发出的红外光直接反射回接收端，形成并非来自目标的“串扰”。XTalk 补偿用于扣除这部分背景信号。

- 补偿过小：远处目标可能被测得过近，读数容易漂移；
- 补偿过大：有效目标信号被过度扣除，可能增加无效测量；
- 不同盖板、装配间隙和污染状态需要不同值，不能照抄另一台设备。

## 自动校准条件

当前校准约采集 50 个样本，通常需要约 5 秒，最长等待约 15 秒。校准时：

1. 清洁传感器窗口；
2. 对准反射均匀的空白墙面或天花板；
3. 参考目标距离至少约 `1.5 m`；
4. 传感器前 `1.5 m` 内不要有其他物体；
5. 保持设备固定，等待完成提示；
6. 完成后在多个已知距离复核。

校准会先清除当前 XTalk，再根据采样信号估算新值。中途遮挡、晃动或对准强反光小物体都会污染结果。

## 距离范围与刷新

当前驱动使用长距离模式和约 `200 ms` 测量预算，主程序约每 `500 ms` 轮询一次。近似状态：

- `50–2000 mm`：作为正常有效距离；
- 约 `2–3 m`：显示对应超范围状态；
- 更远：显示另一超范围状态；
- 短暂无效时可能保持上一有效状态，而不是立即跳为零。

这些边界用于稳定设备交互，不代表 VL53L0X 在所有目标反射率和环境光下都能达到相同精度。

## 与自动视差的关系

自动视差使用距离在五个 X 锚点之间插值。若距离值本身偏差很大，视觉对齐曲线即使标得很细也会出错。因此应先校准距离，再校准视差。

VL53L0X 与触摸设备共享 I²C 资源的硬件实现可能受具体批次影响。若触摸和测距同时异常，应一并检查供电、连线、I²C 地址和总线日志，而不只修改 XTalk。
