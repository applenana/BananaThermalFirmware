# 融合

上一篇：[摄像头](10-camera.md) · [返回菜单总览](README.md) · 下一篇：[滤波设置](12-filtering.md)

融合把热成像的温度颜色与可见光的结构细节组合。它依赖摄像头初始化和两路画面对齐；对齐不准时，融合会出现明显重影。

## 参数

| 参数 | 选项 / 范围 | 当前默认值 |
| --- | --- | --- |
| 融合模式 | 关闭 / 混合 / 边缘 / 半采样 | 混合 |
| 融合透明度 | `0–255`，步长 `5` | `126` |
| 边缘阈值 | `0–255`，步长 `5` | `126` |
| 边缘颜色 | 深灰 / 米白 | 深灰 |
| Gamma | 约 `0.2–5.0`，步长 `0.1` | `1.0` |
| 旋转 | `0° / 90° / 180° / 270°` | `270°` |
| 水平镜像 | 开 / 关 | 关 |
| 垂直镜像 | 开 / 关 | 关 |
| 红蓝交换 | 开 / 关 | 关 |

## 四种模式

| 模式 | 处理方式 | 适用情况 |
| --- | --- | --- |
| 关闭 | 只显示热成像 | 只关心温度，或摄像头不可用 |
| 混合 | 按透明度混合完整可见光与伪彩热像 | 观察温度与物体纹理 |
| 边缘 | 从可见光提取边缘并叠加到热像 | 希望保留热像颜色，同时看清轮廓 |
| 半采样 | 在较低分辨率缓冲上混合 | 降低计算量，代价是细节降低 |

## 融合透明度

当前实现使用 `0–255`：

- `0`：更偏向可见光；
- `255`：更偏向热成像；
- 中间值：两者按比例混合。

它与[温度图例透明度](07-colormap-and-legend.md)无关。前者控制两幅图像的混合权重，后者只控制图例卡片背景。

## 边缘阈值和颜色

阈值决定多强的可见光亮度变化才被判定为边缘：

- 阈值较低：保留更多细节，也更容易把噪声和纹理算成边缘；
- 阈值较高：只保留强轮廓，画面更干净；
- 深灰适合浅色热像背景，米白适合深色背景。

边缘模式仍依赖两路几何对齐。阈值不能修复位置错位。

## Gamma

Gamma 对可见光亮度做非线性调整：

- `1.0`：不做额外变化；
- 小于 `1.0`：通常提亮中间亮度；
- 大于 `1.0`：通常压暗中间亮度。

在调 Gamma 前先确认摄像头曝光和采集稳定。过大的 Gamma 会压掉暗部，过小则可能让亮部发白。

## 旋转、镜像和红蓝交换

这些参数用于适配摄像头模块的安装方向和 RGB565 数据顺序：

- 先用旋转让画面方向正确；
- 再用水平/垂直镜像匹配实际安装；
- 若几何方向正确但红、蓝明显颠倒，使用红蓝交换。

“红蓝交换”只修正摄像头/融合链路，不等同于[反色设置](13-color-inversion.md)里的屏幕 RGB/BGR 顺序。

## 推荐调节顺序

1. 先完成[摄像头](10-camera.md)全屏和方屏的几何对齐；
2. 配置旋转、镜像和红蓝交换；
3. 选择混合模式调透明度；
4. 再按需要使用边缘或半采样模式；
5. 有 VL53L0X 时最后配置[视差调整](15-parallax.md)。

## 与上位机的关系

上位机可分别接收浮点热流和 RGB565 可见光流，在更强算力的一端重新融合。设备菜单的融合适用于本机 LCD；上位机自己的融合参数不应假设与设备同步。
