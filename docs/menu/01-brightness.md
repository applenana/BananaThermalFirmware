# 亮度

[返回菜单总览](README.md) · 下一篇：[卡尔曼滤波](02-kalman-filter.md)

亮度栏目控制 LCD 背光强度，不改变热成像数据、测温结果、照片内容或推流数据。

## 参数

| 参数 | 范围 | 当前默认值 | 说明 |
| --- | --- | --- | --- |
| 屏幕亮度 | `0–256`，步长 `1` | `255` | `0–255` 使用 PWM 调光；`256` 显示为 `MAX`，背光持续全开 |

## 怎么选

- 室内通常不需要 `MAX`，降低亮度可以减少刺眼和设备功耗。
- 阳光下看不清屏幕时可以提高亮度。
- 亮度为 `0` 时屏幕看起来会关闭，但设备仍可能在工作；可用按键重新调高。

## 它不会影响什么

USB 推流中的温度值和 RGB565 可见光帧不会因 LCD 亮度改变。若电脑端画面太暗，应在[上位机](https://github.com/applenana/NextBananaThermalStudio)或摄像头相关设置中调整，而不是修改本项。

## 保存

退出栏目时随设备设置一同保存，重启后继续使用。
