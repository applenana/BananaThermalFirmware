# 测温光标

上一篇：[硬盘管理](05-storage.md) · [返回菜单总览](README.md) · 下一篇：[伪彩调整](07-colormap-and-legend.md)

测温光标把热像数组中的温度和屏幕位置对应起来，用于单点、多点以及自动热点/冷点观察。光标只是选取和展示温度，不改变传感器原始数据。

## 参数

| 参数 | 选项 | 当前默认值 | 作用 |
| --- | --- | --- | --- |
| 测温模式 | 单点 / 多点 | 单点 | 单点使用一个主光标；多点最多保留 5 个触摸测温点 |
| 最高温跟踪 | 开 / 关 | 开 | 在当前可见热像区域搜索并跟踪热点 |
| 最低温跟踪 | 开 / 关 | 关 | 在当前可见热像区域搜索并跟踪冷点 |
| 跟踪显示 | 仅光标 / 光标+温度 | 光标+温度 | 决定自动热点、冷点旁是否直接绘制数值；已保存配置优先 |
| 光标跟踪 | 最冷 / 最热 / 中心 / 手动 | 中心 | 决定主光标的位置来源 |
| 测温字号 | `1×` / `1.5×` / `2×` | `1.5×` | 主光标温度数字大小 |
| 高温字号 | `1×` / `1.5×` / `2×` | `1.5×` | 热点数字大小 |
| 低温字号 | `1×` / `1.5×` / `2×` | `1.5×` | 冷点数字大小 |
| 数字背景 | 透明 / 黑色 / 白色 | 黑色 | 提高文字在不同伪彩背景上的可读性 |

## 单点与多点

- 单点模式适合连续观察一个位置，主光标可固定在中心、手动移动，或跟随最冷/最热位置。
- 多点模式适合比较多个目标。触摸屏最多记录 5 个点。
- 切换模式会清空旧的多点触摸记录，并重置相应温度平滑状态。
- 选择“最冷、最热、中心、手动”中的任一主光标方式时，固件会回到单点逻辑并清理旧的多点记录。

## 热点和冷点如何确定

固件在当前可见热像范围内寻找最高或最低温位置，并对边缘无效点、短暂跳动做一定处理。跟踪结果不是独立传感器读数，它仍来自热像素阵列：

- 热像缩放、偏移和方屏裁剪会改变“当前可见区域”；
- 热源很小且没有充分覆盖一个热像素时，读数会被周围背景稀释；
- 强反射和错误发射率也会产生看似很热或很冷的位置。

## 光标位置与屏幕模式

全屏和方屏有不同的逻辑中心与热像变换。切换[全屏调整](09-display-mode.md)时，固件会把光标规范到新画面的有效范围，避免沿用超出边界的坐标。

上位机通过 `thermal view` 获得缩放、偏移和旋转后，会把热像坐标映射到自己的画布。相关协议见[双光串口推流协议](../STREAMING_PROTOCOL.md)。

## 使用建议

- 需要读数清晰时选择黑色或白色背景；需要尽量少遮挡画面时选择透明。
- 同时开启热点、冷点、主光标和图例会占用较多屏幕空间，可通过“跟踪显示”或[图例详情](07-colormap-and-legend.md)精简。
- 对精确位置测温，优先让目标覆盖多个热像素，并保持稳定距离，而不是只依赖放大后的屏幕像素。
