# 视差调整

上一篇：[温度报警](17-temperature-alarm.md) · [返回菜单总览](README.md) · 下一篇：[距离传感器](16-distance-sensor.md)

> 本栏目只在 VL53L0X 距离传感器初始化成功后显示。

热传感器和可见光摄像头安装在不同位置，看到同一个近距离目标时会产生横向视差。固定 X 偏移只能在一个距离附近对齐；自动视差会根据实测距离在多个标定锚点之间插值。

## 参数

| 参数 | 范围 | 当前默认值 | 说明 |
| --- | --- | --- | --- |
| 视差模式 | 手动 / 自动 | 手动 | 自动模式随距离更新；手动模式保持固定摄像头基准 |
| 自动基准 | `-1000–1000` | `0` | 加到所有自动锚点插值结果上的全局修正 |
| `0.10 m` 锚点 | `-300–300` | `250` | 距离 10 cm 时的 X 补偿 |
| `0.25 m` 锚点 | `-300–300` | `112` | 距离 25 cm 时的 X 补偿 |
| `0.50 m` 锚点 | `-300–300` | `60` | 距离 50 cm 时的 X 补偿 |
| `1.00 m` 锚点 | `-300–300` | `40` | 距离 1 m 时的 X 补偿 |
| `2.00 m` 锚点 | `-300–300` | `0` | 距离 2 m 时的 X 补偿 |

补偿作用在摄像头 X 方向，不改写热流温度或热像缩放。

## 自动插值

在两个锚点之间，固件做分段线性插值。例如 `0.25 m` 为 `112`、`0.50 m` 为 `60`，中间距离会得到两者之间的连续补偿。

- 小于 `0.10 m`：使用最近端锚点；
- 大于 `2.00 m`：使用最远端锚点；
- 距离暂时无效：不会凭空推断新距离，会保持可用状态。

“自动基准”会整体平移曲线，适合设备装配造成的统一偏差；若只有某个距离不准，应修改对应锚点，而不是大幅修改自动基准。

## 手动模式

当前菜单没有独立的“手动视差 X”编辑项。手动模式下，实际固定对齐主要通过[摄像头](10-camera.md)或快捷菜单的 X 偏移完成。启用自动模式后，固件在这个物理基准之上施加动态补偿。

保存摄像头参数时，固件会先排除已经应用的动态视差量，避免把某个距离下的瞬时补偿永久叠加进基础偏移。

## 标定方法

1. 先完成触摸、热像方向和可见光旋转配置；
2. 在全屏或方屏模式中调好热像缩放与两路基础中心；
3. 确认[距离传感器](16-distance-sensor.md)读数可靠；
4. 把清晰、温差明显且大致平面的目标依次放在五个标定距离；
5. 在每个距离调整锚点，使可见光边缘与热像边缘重合；
6. 来回移动目标，检查插值区间是否连续；
7. 对整体残余偏差只做少量“自动基准”修正。

全屏和方屏有独立摄像头/热像基础配置，但当前视差锚点是设备级共同参数。标定后应在两种屏幕模式都复核。

## 常见问题

| 现象 | 可能原因 |
| --- | --- |
| 近处对齐、远处错位 | 锚点曲线不合适或目标距离读数错误 |
| 所有距离都向同一方向偏 | 自动基准或基础摄像头 X 不正确 |
| 自动模式来回跳 | 距离反射质量差、串扰未校准或目标太小 |
| 保存后偏移突然叠加 | 应检查固件版本和视差隔离保存逻辑 |
