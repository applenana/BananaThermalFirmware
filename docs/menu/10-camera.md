# 摄像头

上一篇：[全屏调整](09-display-mode.md) · [返回菜单总览](README.md) · 下一篇：[融合](11-fusion.md)

摄像头栏目校准可见光采集窗口和时序。它只在摄像头初始化成功后可用。全屏和方屏各自保存一套 X、Y、缩放参数，以便两种布局独立对齐。

## 参数

| 参数 | 作用 | 范围 / 说明 |
| --- | --- | --- |
| 全屏 X / Y | 移动全屏模式的可见光传感器裁剪窗口 | 每次按“偏移步长”移动 |
| 全屏缩放 | 改变全屏模式可见光取景范围 | OV2640 约 `240–600`；OV3660 约 `320–1536` |
| 方屏 X / Y | 移动方屏模式的可见光传感器裁剪窗口 | 每次按“偏移步长”移动 |
| 方屏缩放 | 改变方屏模式可见光取景范围 | 同上，独立保存 |
| 热像 X / Y | 移动当前屏幕模式的热像显示位置 | `-100–100` 屏幕像素 |
| 偏移步长 | X/Y 每次调整量 | `1–128`，默认 `4` |
| 摄像头时钟 | 调节摄像头输出时序 | OV3660 为 PCLK 比例 `2–12`；OV2640 为 CLKRC 分频 `0–7` |
| 垂直同步 | 是否等到新帧起点后再取图 | 默认关 |

当前屏幕模式对应的参数前会显示 `>`。

## 三类“偏移”不要混淆

- 全屏 X/Y、方屏 X/Y：改变可见光传感器裁剪窗口，单位接近传感器采样坐标。
- 热像 X/Y：改变当前模式热像在 LCD 上的位置，单位是屏幕像素。
- [视差调整](15-parallax.md)：根据距离额外改变摄像头 X，用来补偿双镜头不在同一物理位置。

固件保存摄像头基础位置时会先撤回动态视差，避免把某一时刻的距离补偿错误写进永久基准。

## 缩放

这里的缩放值表示摄像头裁剪高度，数值越大通常取景越广、目标看起来越小；数值越小通常取景越窄、目标看起来越大。具体上下限随 OV2640 / OV3660 不同。

建议先调缩放让可见光视场与热像大致一致，再调 X/Y；若顺序相反，后续缩放可能让边缘重新错位。

## 时钟与垂直同步

- 降低摄像头数据速度可能缓解某些硬件批次的竖纹或不稳定，但也会降低可见光帧率。
- 开启垂直同步会等待完整帧边界，有助于减少撕裂，代价是等待时间和吞吐变化。
- OV2640 的菜单时钟值在当前实现中是栏目内运行时变量，没有像其他摄像头配置一样明确持久化；重启后应重新确认。

除非正在排查竖纹、撕裂或采集不稳定，不建议随意修改时钟。

## 推荐对齐顺序

1. 关闭自动视差，选择一个中等距离的平面目标；
2. 选定[全屏或方屏](09-display-mode.md)；
3. 调可见光缩放，使两路视场尺寸接近；
4. 调可见光 X/Y，使中心或明显边缘对齐；
5. 用热像 X/Y做少量屏幕级微调；
6. 对另一种屏幕模式重复；
7. 最后配置[融合](11-fusion.md)和[自动视差](15-parallax.md)。

## 与推流的关系

可见光推流使用当前屏幕模式对应的固定输出规格：全屏 `120 × 160`，方屏 `120 × 120`，每帧仍带自己的宽、高和长度。摄像头裁剪、旋转、镜像和色序会影响用户实际看到的 RGB565 内容。
