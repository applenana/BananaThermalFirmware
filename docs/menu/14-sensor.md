# 传感器设置

上一篇：[反色设置](13-color-inversion.md) · [返回菜单总览](README.md) · 下一篇：[温度报警](17-temperature-alarm.md)

本栏目调整热传感器显示方向、热像视图和采集节奏，并按检测到的传感器显示专用选项。

## 通用参数

| 参数 | 选项 / 范围 | 当前默认值 | 说明 |
| --- | --- | --- | --- |
| 热像旋转 | `0° / 180°` | dual 180°；standard 按传感器 | 单光 MLX 首次 180°，Heimann 首次 0°；保存配置优先 |
| 热像缩放 | `1.0–2.0×`，步长 `0.1×` | `1.0×` | 以视图中心放大热像 |
| 速率模式 | 极速 / 舒适 | 极速 | 主循环延时约为 `2 ms / 100 ms` |
| 光学旋转 | `0° / 180°` | 取决于当前配置 | 仅 OV3660 摄像头显示 |

热像缩放、X/Y 偏移按[全屏与方屏](09-display-mode.md)分别保存。放大不会增加传感器物理像素，只会缩小可见视野并放大插值结果。

## 速率模式

- 极速：主循环末尾只短暂延时约 `2 ms`，追求更及时的显示和交互。
- 舒适：每轮增加约 `100 ms` 延时，降低更新频率，可在某些设备上减少闪烁或负载。

它不是热传感器硬件刷新率本身。MLX 的硬件刷新率由下面的“MLX 速率”独立设置。

## MLX90640 / MLX90641 专用：MLX 速率

| 可选值 | 含义 |
| --- | --- |
| `4 Hz` | 较低总线和计算负担，运动响应慢 |
| `8 Hz` | 稳定与响应折中 |
| `16 Hz` | 共用初始默认，适合一般实时观察 |
| `32 Hz` | standard 单光首次 MLX 默认；对总线、算力和供电要求更高 |

修改请求会由传感器采集循环应用，避免菜单与采集同时访问总线。MLX90640 需要两个子页组成完整帧，因此菜单频率不能简单等同于最终完整画面帧率；推流、可见光和渲染也会占用时间。

若 `32 Hz` 下出现读帧失败、闪烁或系统不稳定，先退回 `16 Hz` 或 `8 Hz`，不要只调整卡尔曼掩盖采集问题。

## Heimann HTPA32x32 专用：恢复出厂 Trim

海曼传感器会显示“恢复出厂 Trim”操作。它把 EEPROM 中的校准 Trim 恢复到用户区并重新应用，属于传感器级维护操作：

- 只在确认 Trim 被错误修改或维护流程明确要求时使用；
- 操作期间不要断电；
- 完成后检查传感器初始化、温度稳定性和坏点；
- 这不是普通的“恢复菜单默认值”。

菜单会显示异步执行状态。若失败，不要反复快速触发，应记录日志和硬件信息。

## 旋转与上位机链路复原

热像旋转会通过 `thermal view` 的 `sensor_rotate180` 返回给最新上位机。上位机先按传感器与屏幕模式恢复逻辑热像，再应用缩放、偏移和旋转。详见[传感器与显示模式](../SENSORS_AND_DISPLAY.md)和[推流协议](../STREAMING_PROTOCOL.md)。

摄像头方向则由[融合](11-fusion.md)中的旋转/镜像控制。热像和可见光方向都正确后，才能进行精确对齐。
