# 伪彩调整

上一篇：[测温光标](06-measurement-cursor.md) · [返回菜单总览](README.md) · 下一篇：[触屏调整](08-touchscreen.md)

伪彩把温度范围映射成颜色，帮助人眼更快发现温差。它只改变显示方式，不改变浮点温度值。

## 色板参数

| 参数 | 选项 | 当前默认值 |
| --- | --- | --- |
| 当前伪彩 | 经典、鲜艳、热值、翠绿、地狱、白热、黑热 | 运行时当前选择 |
| 启动伪彩 | 同上 | 鲜艳 |

色板用途大致如下：

| 色板 | 特点 |
| --- | --- |
| 经典 | 多色热成像风格，温区分辨直观 |
| 鲜艳 | 类 Turbo 连续色带，局部层次丰富 |
| 热值 | 黑—红—黄—白的直观热度表达 |
| 翠绿 | 类 Viridis，亮度变化相对均匀 |
| 地狱 | 类 Inferno，暗背景下对热点醒目 |
| 白热 | 温度越高越亮，适合观察结构 |
| 黑热 | 温度越高越暗，符合部分巡检习惯 |

“当前伪彩”立即影响本次使用；“启动伪彩”决定下次启动时首先加载哪套色板。

## 温度图例

| 参数 | 选项 | 当前默认值 | 说明 |
| --- | --- | --- | --- |
| 温度图例 | 开 / 关 | 开 | 控制整条图例是否显示 |
| 图例位置 | 右上、右下、左上、左下、左中、右中、自定义、信息栏 | 信息栏 | 信息栏使用窄竖条，减少遮挡 |
| 图例透明度 | `0% / 25% / 50% / 75% / 100%` | `75%` | 只控制图例卡片底色，不隐藏彩条、数字或刻度 |
| 图例详情 | 开 / 关 | 开 | 控制最高/最低温数字、单位和中间刻度 |

`100%` 透明度表示卡片背景完全透明，彩条和已启用的数字、刻度仍会保留。若只想看彩条，应关闭“图例详情”；若什么都不显示，应关闭“温度图例”。

选择“自定义”后，可在热像画面中拖动图例到合适位置。拖动由触摸命中区域处理，不会被识别为普通手势。

## 温度范围从哪里来

图例上下限来自当前用于着色的显示温度范围，通常随画面最高、最低温自动变化。[滤波设置](12-filtering.md)中的“最小显示温差”会在场景温差很小时撑开这个范围，避免微小噪声占满整套色板。

因此：

- 图例范围变化不代表原始温度被改写；
- 同一温度在不同帧里可能因为自动范围不同而显示成不同颜色；
- 比较不同时间的绝对颜色前，应同时看图例数值。

## 设备与上位机

[NextBananaThermalStudio](https://github.com/applenana/NextBananaThermalStudio)会使用收到的浮点温度重新生成自己的色板和图例。设备本机的色板、图例位置和透明度不会通过热流强制同步到上位机；两端可独立调整。

## 当前实现提示

当前源码中“启动伪彩”的左右切换分支都按递减方向循环，右键不会按预期向前选择。这是现有实现缺陷，不是菜单设计。遇到时可继续循环到目标色板，等待后续固件修复。
