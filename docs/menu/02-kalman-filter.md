# 卡尔曼滤波

上一篇：[亮度](01-brightness.md) · [返回菜单总览](README.md) · 下一篇：[发射率](03-emissivity.md)

卡尔曼滤波是一种根据“上一时刻的估计”和“这一时刻的测量”持续更新结果的方法。设备为每个热像素维护独立状态，用它减少传感器噪声造成的温度跳动和伪彩闪烁。

它是时间滤波：比较同一像素前后多帧的变化。它和[滤波设置](12-filtering.md)中的空间滤波不同，后者比较同一帧内相邻像素。

## 当前计算

每次更新大致执行：

```text
P = P + Q
K = P / (P + R)
输出 = 输出 + K × (本次测量 - 输出)
P = (1 - K) × P
```

`K` 是本次测量对结果的影响比例。菜单不直接编辑 `P` 和 `K`，只编辑决定它们变化的 `Q`、`R` 和每图滤波次数。

## 参数

| 参数 | 范围 / 步长 | 当前默认值 | 调大后的主要效果 |
| --- | --- | --- | --- |
| Q（过程噪声） | 最小 `0.01`，步长 `0.01`；菜单当前没有上限 | `0.10` | 更相信场景正在变化，响应更快、平滑更弱 |
| R（测量噪声） | 最小 `0.01`，步长 `0.01`；菜单当前没有上限 | `1.75` | 更不相信传感器当前读数，结果更平稳、响应更慢 |
| 每图滤波次数 | `1–8` | `4` | 同一张新传感器帧会进行更多次状态推进，更快逼近该帧，但也增加计算量 |

“每图滤波次数 = 1”接近旧版每张传感器帧只更新一次的行为。多次更新是同一新帧的重复收敛，不会凭空增加传感器真实刷新率。

上表为共用初始值；standard 单光首次按传感器类别应用默认时，两类传感器均把每帧次数设为 8，Heimann 另将 Q 设为 0.5、R 设为 1.75。默认值按版本标记保存，之后不在每次启动覆盖用户修改。具体见[传感器与显示](../SENSORS_AND_DISPLAY.md)。

## 调节建议

| 现象 | 优先尝试 |
| --- | --- |
| 静止物体画面仍明显闪烁 | 增大 `R`，或小幅减小 `Q` |
| 移动目标出现明显拖尾 | 增大 `Q`，或减小 `R` |
| 新温度出现后收敛太慢 | 提高每图滤波次数，或增大 `Q` |
| 设备刷新负担偏高 | 降低每图滤波次数 |

建议一次只调整一个参数，并观察静止区域噪声和移动目标拖尾。`Q` 与 `R` 的相对关系比单个数值更重要。

## 与其他功能的关系

- [发射率](03-emissivity.md)和[温度校准](04-temperature-calibration.md)先改变温度，卡尔曼再对结果做时间平滑。
- [快速插值](12-filtering.md)只跳过空间滤波，不会关闭卡尔曼。
- 设备卡尔曼影响设备输出的温度；[NextBananaThermalStudio](https://github.com/applenana/NextBananaThermalStudio)还可在接收端增加自己的显示滤波。两层同时设得很强会产生更明显的延迟。

## 注意事项

当前菜单只限制 `Q`、`R` 的下限而不限制上限。极大数值可能让滤波失去意义或造成非常迟钝的结果，应逐步调整并保留原值以便恢复。
