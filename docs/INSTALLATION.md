# 安装与升级指南

## 升级前

先确认以下信息：

- 板型是 `standard` 单光还是 `dual` 双光，参见[设备分类](devices/README.md)；
- Flash 容量是 8 MB 还是 2 MB；
- 当前固件版本；
- 设备使用 MLX 还是 Heimann 传感器；
- 是否保存了照片、温度校准、触屏校准、摄像头裁剪或热像偏移参数；
- 对应 Release Notes 是否要求迁移配置。

升级前备份设备照片和重要参数。Flash 分区变化可能使旧文件系统无法读取。

## 旧单光首次迁移

2.4 / 2.8 / 3.2 寸单光在相同 Flash 与运行配置下共用 `standard` UF2，最低需要统一固件 v1.8.0。旧单光 v2.2 与统一 v1.8.x 是不同版本线，Studio 将其识别为迁移，不按普通降级处理。

**首次迁移会重建 LittleFS，清空照片、配置和校准。** 仅在旧分区可挂载且激活信息有效时尝试恢复激活；不能承诺跨分区保留。先导出原始照片、记录校准与发射率、触摸和方向等参数，并保留售后激活资料。

升级后的两键机可用 A+B 进入与确认菜单，A/B 作为左右键；3.2 寸仍可使用拨片。单光不会获得可见光、融合、测距或独立快捷菜单键。完整操作见[单光说明书](user-guide/single-light.md)。

## 下载和校验

1. 从本仓库 Releases 按[六固件矩阵](FIRMWARE_VARIANTS.md)选择板型、实际 Flash 容量和性能/稳定配置，下载对应 UF2；
2. 同时下载 `SHA256SUMS`、`SHA256SUMS.sig` 和 `firmware-release-allowed-signers`；
3. 按[发布完整性与签名](RELEASE_INTEGRITY.md)完成校验；
4. 校验失败时删除下载文件并重新下载，不要继续刷写。

## 进入 UF2 Bootloader

不同外壳与批次入口可能不同。有明确 A/BOOTSEL 和复位键时：

1. 以支持数据的 USB 线连接电脑，保持供电；
2. 按住 A / BOOTSEL；
3. 短按并松开 RESET，继续按住 A；
4. 电脑出现 RP2040 Bootloader 可移动磁盘后松开 A。

若使用按住 BOOTSEL 再上电的方式，必须确保设备确实完全断电；内置电池仍供电时，只拔 USB 不等于重启。原 2.8 寸说明书未明确复位入口，按实物资料、售后指导或 Studio 支持的升级流程进入，不能把挂绳孔当成复位孔。

如果设备外壳没有标记 BOOT / RESET，请查阅对应硬件说明，不要拆机短接未知焊盘。

## 刷写

1. 将正确的 UF2 复制到 Bootloader 可移动磁盘；
2. 等待复制完成；
3. 设备通常会自动断开磁盘并重启；
4. 首次启动可能需要初始化或迁移配置，请不要立刻断电。

## 升级后验证

- 版本信息与目标 Release 一致；
- `GetSysInfo` 或 Studio 识别的 `hardwareProfile` 与实物一致；
- 正确识别 MLX90640、MLX90641 或 Heimann HTPA32x32；
- 全屏 `320 × 240` 与方屏 `240 × 240` 均能显示；
- 最高温、最低温和平均温合理；
- 双光：可见光、融合及已安装的测距模块正常；单光：保持纯热像，Studio 隐藏双光操作；
- NextBananaThermalStudio 能够获取 `thermal view` 并投屏；
- 普通升级：检查照片和配置；旧单光首次迁移：重新设置与校准，并检查激活；
- 需要报警时检查阈值、迟滞和解除；刷写后不要默认认为原报警配置还在。

## 回退

如需回退：

1. 阅读旧版本是否使用相同 Flash 分区和配置格式；
2. 重新进入 Bootloader；
3. 刷入经过签名校验的旧版 UF2；
4. 必要时恢复备份。

新版本写入的新格式不一定能被旧固件读取。涉及文件系统和照片格式迁移时，不建议直接跨多个版本回退。
